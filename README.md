# ECON UN3412 midterm study guide

Study guide for the Fall 2026 Introduction to Econometrics midterm (Wednesday, October 28):
lecture notes for Lectures 1–9 with concept checks, worksheet and recitation solutions,
a problem-set guide (concepts, tools and formulas for each question, no answers),
a formula sheet and a practice exam.

The whole site is `index.html`. It is published with GitHub Pages at
https://etd2122.github.io/econ-un3412-guide/
